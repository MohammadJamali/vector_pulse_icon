# vector_pulse_icon example

A gallery of every ready-made animation in `IconAnimations`, plus a grouped
pulse sequence, all played on the sample icon in `assets/icon.svg`.

The sample icon has three parts: the top and bottom petals (one `<g>`), the
left and right petals (another `<g>`) and the centre dot.

This folder has no platform projects. Generate the ones you need, then run:

```sh
flutter create --platforms=windows,macos,linux,web .
flutter run
```
